## 一、现状流程图（人工模式）

```mermaid
flowchart LR
  subgraph S["门店 / 店长"]
    A1["巡店发现缺货<br/>纸质登记 / 拍照"]
    A2["微信群 / 电话告知<br/>38% 消息无明确数量"]
    A11["收货后手工改<br/>门店库存表"]
    A12["数量 / 效期差异<br/>微信群反馈、事后补单"]
  end

  subgraph P["补货中心 / 计划员"]
    B1["导出 Excel<br/>手工汇总销量与库存"]
    B2["手工算建议量<br/>仅 300/1842 SKU 有公式"]
    B3["按经验修正<br/>新品 / 促销无历史"]
    B4["生成补货单 Excel<br/>v3 → v5 → v7"]
    B5["周会复盘<br/>缺货率三个口径"]
  end

  subgraph L["仓配 / 区域物流"]
    C1["核对在途 / DC 库存<br/>与门店表差 37 处"]
    C2["按线路人工合并<br/>再手工拆单"]
    C3["DC 库存不足<br/>电话协调跨店调拨"]
  end

  subgraph D["系统与数据"]
    E1["POS 日结 T+1<br/>WMS 库存手工导出"]
  end

  A1 --> A2
  E1 -.手工导出.-> B1
  A2 ==电话/微信==> B1
  B1 --> B2
  B2 --> C1
  C1 ==回填==> B3
  B3 --> B4
  B4 --> C2
  C2 --> C3
  C3 ==到货==> A11
  A11 --> A12
  A11 --> B5
```

**读图要点**

- 3 处人工转录：巡店登记 → 微信 → Excel → 邮件（每次转录都丢信息）。
- 2 处口径不一致：在途/DC 库存 vs 门店库存表；周会缺货率三个口径。
- 1 处无审批痕迹：差异只走微信群，事后补单。
- 关键结构性缺陷：门店收货后手工改表，使 WMS 与门店账长期不一致，反过来污染下一次建议量。

## 二、数智化转型后流程图（规则 + 例外管理）

```mermaid
flowchart LR
  subgraph D["系统与数据"]
    F1["数据自动汇聚<br/>POS / 库存 / 在途 / 效期<br/>06:30 生成快照"]
    F2["缺货识别<br/>库存 ≤ 0 且 POS 零销售<br/>或低于最小陈列量"]
    F3["需求基线<br/>近 7 日日均 / 波动 CV<br/>→ 置信度三档"]
    F4["建议量引擎<br/>安全库存 + 陈列覆盖<br/>+ 起订量取整"]
    F5["硬约束校验<br/>效期 / 上限 / 权限<br/>/ 重复 / 新鲜度"]
    F8["高置信批量流转<br/>计划员抽检"]
    F12["指标看板<br/>时长 / 返工 / 正确率<br/>/ 采用率 / 复核成本"]
  end

  subgraph S["门店 / 店长"]
    G1["店长扫码补充上报<br/>选店 → 勾 SKU → 提交"]
    G3["异常升级<br/>缺数据 / 低置信 / 越权<br/>→ 具名接收人"]
    G4["扫码收货<br/>差异自动开异常单"]
  end

  subgraph P["补货中心 / 计划员"]
    H1["例外复核<br/>仅 medium / low 置信<br/>改量必填理由"]
    H2["一键下发补货单<br/>带快照 ID + 规则 ID"]
  end

  subgraph L["仓配 / 区域物流"]
    I1["DC 不足 → 调拨评分<br/>效期 / 富余 / 距离 / 装载"]
  end

  F1 --> F2
  G1 --> F2
  F2 --> F3
  F3 --> F4
  F4 --> F5
  F5 -- E_* 错误码 --> G3
  F5 -- 例外 --> H1
  F5 -- 高置信 --> F8
  H1 --> H2
  F8 -.批量.-> H2
  H2 --> I1
  H2 ==到货==> G4
  I1 ==到货==> G4
  G4 --> F12
```

**与原流程的差异**

| 环节 | 现状 | 转型后 |
|---|---|---|
| 缺货信号 | 店长口头/微信，38% 无数量 | 系统识别 + 店长 3 步补充，结构化入库 |
| 算量 | 计划员手工 Excel，仅 300 个 SKU 有公式 | 规则引擎统一公式，参数按品类可配 |
| 校验 | 事后追责（差异微信群反馈） | 事前硬约束（效期/上限/权限/重复/新鲜度） |
| 复核 | 全量人工核对 | 只审例外（预计约 12% 单据） |
| 调拨 | 电话协调、靠人情 | 5 因子评分 + 叶书审批 + 留痕 |
| 收货 | 手工改表，账实长期不符 | 扫码收货，差异自动开单 |
| 指标 | 周会三个口径 | 看板实时，口径唯一 |

## 三、如何重新导出图片

```bash
python3 tools/gen_flow.py          # 生成 docs/*.svg
python3 - <<'EOF'
import pymupdf
for f in ["docs/03-流程图-现状.svg", "docs/03-流程图-数智化转型后.svg"]:
    d = pymupdf.open(f)
    d[0].get_pixmap(dpi=150).save(f.replace(".svg", ".png"))
EOF
```
